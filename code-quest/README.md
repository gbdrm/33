# CodeQuest - Learn to Code Through Adventure

An interactive browser-based game that teaches JavaScript programming through progressive coding challenges.

## 🎮 Features

- **12 Progressive Challenges** - From basics like "Hello World" to advanced concepts like FizzBuzz
- **Real-time Code Execution** - Write and run JavaScript code directly in your browser
- **Instant Feedback** - Automated tests validate your solutions immediately
- **Gamification** - Earn XP, level up, and unlock achievements
- **Beautiful UI** - Modern, dark-themed interface with smooth animations
- **Progress Tracking** - Your progress is automatically saved in local storage
- **Hints System** - Get help when you're stuck

## 🚀 How to Play

### Option 1: Simple (No Server)
Just open `index.html` in your web browser!

### Option 2: Local Server (Recommended)
```bash
cd code-quest
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

### Option 3: Using Node.js
```bash
npx serve code-quest
```

## 🧪 Testing

Want to verify all challenges work correctly? Open `test.html` in your browser or visit `http://localhost:8080/test.html` when running a local server. This page automatically tests all 12 challenges with sample solutions and shows detailed results.

## 📚 What You'll Learn

### Easy Challenges
1. **Hello World** - Console output basics
2. **Variables and Math** - Variable declaration and arithmetic
3. **String Concatenation** - Working with strings
4. **If Statements** - Conditional logic

### Medium Challenges
5. **For Loop Basics** - Iteration fundamentals
6. **Arrays** - Array creation and indexing
7. **Functions** - Function declaration and calling
8. **Array Methods** - Using `.map()` for transformations

### Hard Challenges
9. **Objects** - Object creation and property access
10. **Filter Array** - Using `.filter()` for data filtering
11. **Arrow Functions** - Modern JavaScript syntax
12. **FizzBuzz Challenge** - Classic programming problem

## 🎯 Game Mechanics

- **XP System**: Earn experience points for completing challenges
- **Levels**: Level up every 500 XP
- **Score**: Accumulate points for your total achievement
- **Achievements**: Unlock badges as you progress:
  - 🎯 First Steps (Complete 1 challenge)
  - ⚡ Quick Learner (Complete 3 challenges)
  - 🌟 Halfway There (Complete 6 challenges)
  - 👑 Code Master (Complete all 12 challenges)
  - 💎 High Scorer (Reach 1000 points)
  - 🔥 XP Hunter (Earn 500 XP)

## ⌨️ Controls

- **Run Code**: Click "▶ Run Code" button or press `Ctrl + Enter`
- **Reset**: Restore the starter code for current challenge
- **Hint**: Click the hint button when you need help
- **Navigation**: Use Previous/Next buttons to navigate between challenges

## 🎓 Learning Path

CodeQuest is designed to teach JavaScript fundamentals in a structured way:

1. Start with basic output and variables
2. Progress to control flow (if statements, loops)
3. Learn data structures (arrays, objects)
4. Master functions and modern syntax
5. Practice with real-world challenges

## 💡 Tips for Success

- Read the challenge description carefully
- Use the hint button if you're stuck
- Experiment! You can run your code as many times as you need
- Pay attention to test results - they tell you what's missing
- Try to understand why a solution works, not just make it pass
