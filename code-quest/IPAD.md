## 🎮 How to Use on iPad

### Getting Started
1. Open the link in Safari (Chrome works too, but Safari is best)
2. Tap "Start Your Journey"
3. Read the challenge description
4. Tap in the code editor to bring up the keyboard
5. Write your code
6. Tap "▶ Run" to test your solution

### Navigation
- **Tap challenges** in the sidebar to switch between them
- **Swipe** to scroll through long code or output
- **Tap "Previous"/"Next"** to move between challenges
- **Tap the hint button** (💡) when you need help

### Code Editing Tips
- Tap exactly where you want to edit
- Use the keyboard's cursor keys to move around
- Long-press for copy/paste menu
- Shake to undo (if enabled in iOS settings)
- Two-finger tap for redo

## ⌨️ Keyboard Shortcuts

### With External Keyboard:
- **Run Code**: Tap the Run button (Ctrl+Enter doesn't work in browser on iOS)
- **Select All**: Cmd+A
- **Copy**: Cmd+C
- **Paste**: Cmd+V
- **Undo**: Cmd+Z
- **Tab**: Adds indentation (4 spaces)

### Code Symbols:
Access these via the iPad keyboard's number/symbol panels:
- `()` - Parentheses (shift+9, shift+0)
- `[]` - Brackets
- `{}` - Braces
- `'` - Quotes
- `;` - Semicolon
- `=` - Equals

## 💡 Pro Tips for iPad

### Performance
- Close other tabs if Safari feels slow
- Clear Safari cache occasionally (Settings → Safari → Clear History)
- Restart Safari if you have issues

### Typing Code
- Use the **code keyboard** layout (tap `123` then `#+=`)
- Long-press keys for alternate characters (e.g., `-` for `_`)
- Enable **Keyboard Trackpad** (long-press space bar) for precise cursor control

### Screen Real Estate
- Hide the sidebar by tapping challenges to save space
- Scroll down to focus on code editor
- Use landscape for maximum space
- Consider an external monitor with iPad Pro

### Saving Your Work
- Progress auto-saves after each challenge
- Don't clear Safari data or you'll lose progress
- Use same device to continue where you left off
- No account needed - everything is local

## 🔧 Troubleshooting

### Keyboard Not Appearing
- Tap directly in the gray code editor area
- Try tapping "Reset" then tapping editor again
- Close and reopen Safari
- Restart your iPad

### Code Not Running
- Make sure you tapped "▶ Run"
- Check for syntax errors in output
- Try "Reset" to start fresh
- Refresh the page if needed

### Layout Issues
- Rotate device to refresh layout
- Reload the page (pull down in Safari)
- Clear Safari cache
- Try a different orientation

### Progress Not Saving
- Make sure you're not in Private Browsing mode
- Don't clear Safari history/data
- Use same iPad device
- Check Settings → Safari → Block All Cookies (should be off)
