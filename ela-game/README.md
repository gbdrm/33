# ELA Quest - English Language Arts Learning Game

An interactive, educational game designed to help students learn and practice English Language Arts skills through engaging activities.

## Features

### 🎮 Five Learning Modes

1. **📖 Vocabulary Match** - Match words with their definitions to build your vocabulary
2. **✏️ Grammar Challenge** - Identify and fix common grammar mistakes
3. **🔤 Spelling Bee** - Practice spelling challenging words with hints
4. **🎯 Parts of Speech** - Identify nouns, verbs, adjectives, adverbs, and more
5. **📝 Reading Quest** - Read passages and answer comprehension questions

## How to Play

### Getting Started

1. Open `index.html` in a web browser
2. Select a game mode from the main menu
3. Answer questions to earn points
4. Track your progress with score and level indicators

### Scoring System

- Each correct answer: **10 points**
- Total score accumulates across all games
- Level up every 100 points
- Progress is saved automatically

### Performance Ratings

- **90-100%**: Outstanding! 🏆
- **70-89%**: Great Job! ⭐
- **50-69%**: Good Effort! 👍
- **Below 50%**: Keep Practicing! 💪

## Game Modes Explained

### Vocabulary Match
Learn new words and their meanings. Each question presents a word and asks you to choose the correct definition from multiple options.

### Grammar Challenge
Identify and correct common grammar mistakes. Learn proper usage of pronouns, verb tenses, possessives, and more.

### Spelling Bee
Type the correct spelling of words based on hints. Perfect for improving spelling skills with commonly misspelled words.

### Parts of Speech
Identify the grammatical function of underlined words in sentences. Learn to recognize nouns, verbs, adjectives, adverbs, prepositions, conjunctions, pronouns, and interjections.

### Reading Quest
Read short passages and answer comprehension questions. Improve reading skills and information retention.

To run locally:

```bash

# Using Node.js
npx serve

php -S localhost:8080
```

Then open `http://localhost:8080` in your browser.
