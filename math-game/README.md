# 🚀 Math Blaster Academy - Super Fun Math Game!

An engaging, interactive math game designed for students in grades 3-6. Features beautiful animations, multiple game modes, and grade-appropriate math challenges!

## ✨ Features

### 🎯 Grade Levels
- **Grade 3**: Addition, subtraction, times tables (1-10), basic division
- **Grade 4**: Multi-digit operations, multiplication/division (1-12), simple fractions
- **Grade 5**: Larger numbers, decimals, powers, advanced operations
- **Grade 6**: Ratios, percentages, simple algebra, complex operations

### 🎮 Game Modes

#### ⚡ Speed Blast
- 60-second time limit
- Answer as many questions as possible
- Race against the clock!

#### 🛡️ Survival Mode
- Start with 3 lives
- Lose a life for each wrong answer
- How far can you go?

#### 🧘 Zen Practice
- No time limits
- No lives - just practice!
- Perfect for learning at your own pace

### 🌟 Game Features
- **Streak System**: Build combos for bonus points!
- **Animated Feedback**: Visual celebrations for correct answers
- **Particle Effects**: Explosions of stars and emojis
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Keyboard Support**: Type numbers 0-9 to answer quickly
- **Beautiful UI**: Gradient backgrounds, smooth animations, and engaging visuals
- **Achievement System**: Unlock special achievements based on performance

## 🎨 Visual Highlights
- Animated starfield background
- Smooth transitions and animations
- Color-coded feedback (green for correct, red for incorrect)
- Pulsing streak counter that changes color at 5 and 10+ streaks
- Particle explosions on every answer
- Responsive buttons with hover effects

## 🎯 Scoring System
- **Base points**: 10 points per correct answer
- **Streak bonus**: +5 points at 5+ streak
- **Super streak bonus**: +10 points at 10+ streak
- **Accuracy tracking**: See your percentage at the end

## 🏆 Achievements
Earn special achievements for:
- High scores (300+, 500+)
- Long streaks (10+, 15+, 20+)
- Speed solving (30+, 50+ correct answers)

## 🚀 How to Play

1. **Choose Your Grade**: Select grade 3, 4, 5, or 6
2. **Pick a Mode**: Speed Blast, Survival, or Zen Practice
3. **Start Playing**: Click or tap the correct answer
4. **Build Streaks**: Answer correctly in a row for bonus points!
5. **Check Your Stats**: See your final score and achievements

## 💻 How to Run

### Option 1: Open Directly
Simply open `index.html` in your web browser.

### Option 2: Local Server
```bash
# Using Python 3
python3 -m http.server 8080

# Then visit http://localhost:8080
```

### Option 3: Node.js Server
```bash
# Install http-server globally (one time)
npm install -g http-server

# Run the server
http-server -p 8080

# Visit http://localhost:8080
```
